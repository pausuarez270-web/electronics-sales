# 🛒 Electronics Sales

A modern and responsive web interface designed for an e-commerce venture, featuring highlighted sections, a shopping cart management system, and interactive product detail views.

---

## ✨ Key Features

* *Intuitive Navigation:* Side drawer menu (hamburger icon) and direct access to the shopping cart from the header.
* *Dynamic Sections:* 
  * 🏷️ *Offers:* Products featuring prominent discount tags (e.g., 50% OFF).
  * 🔥 *Trending:* Popular items or seasonal event highlights.
  * 🎁 *Special Gifts:* Curated categories tailored for specific dates or events.
* *User Interactivity:*
  * *Favorites System:* Heart icon on each product card to save items.
  * Quick *Add to Cart* buttons.
  * *Detailed View Modal:* Clicking on any product opens an expanded view featuring a multi-angle image gallery, pricing, detailed description, and quick purchase actions.

---

## 🚀 Technologies Used

* *HTML5* for semantic structure.
* *Tailwind CSS* for a clean, modern, and fully responsive design.
* *Vanilla JavaScript* for menu toggling, modals, cart behavior, and favorites logic.
